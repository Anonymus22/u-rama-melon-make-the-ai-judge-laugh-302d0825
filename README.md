# Make the AI Judge Laugh — judgelaughx

A single original English one-liner about office life, written to make an AI comedy judge laugh head-to-head against other office jokes. The observation is painfully true (the printer always picks deadline day to jam), the turn is surprising (the machine reads the calendar better than the boss), and the line stays tight at 111 characters.

## The joke

> The office printer only jams on deadline day, which is how I learned it reads the calendar better than my boss.

## How it works

`main.ts` (Node stdlib only) validates the joke — one line, 1–200 characters, non-blank — and writes it to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).
